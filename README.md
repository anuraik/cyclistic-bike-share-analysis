# 🚲 Cyclistic Bike-Share Analysis

## 📌 Project Overview

This project analyses bike-share usage patterns to understand how different types of riders use the service.

The goal is to identify behavioural differences between casual riders and annual members and develop data-driven recommendations.

## 🎯 Business Question

How do casual riders and annual members use bike-share services differently?

## 🔍 Analysis

The analysis will focus on:

- Number of rides
- Ride duration
- Day of the week
- Monthly patterns
- Differences between casual riders and annual members

## 🧹 Data Preparation

The dataset will be cleaned and prepared before analysis.

This will include:

- Checking missing values
- Removing invalid records
- Calculating ride duration
- Creating day-of-week and month variables
- Checking for outliers
